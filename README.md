## Overview
A Unix-like shell implemented in C. It has a command-line interface that allows users to execute common built=in and external commands found in real shells. I created this project in order to apply my learning from systems classes, such as Computer Organization and Architecture & Operating Systems.

## Project Goals
I have currently implemented basic command parsing and execution, with support for commands such as cd, ls, echo, pwd, and history. I currently have this project on hold due to school and work, but I plan to implement more commands in the future.
